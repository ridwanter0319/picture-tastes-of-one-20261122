Entry for the [make.fun](https://make.fun) bounty
[The picture that tastes of one ingredient](https://make.fun/bounty/the-picture-that-tastes-of-one-20261122-2047).

One hero ingredient: chocolate. A macro photograph of glossy molten dark
chocolate poured in a swirling circle around a single cocoa-dusted truffle,
with thin steam, a dark background and warm light.

`main.py` (Python 3.13, standard library only, no network) decodes the
embedded image and writes it deterministically to `/output/entry.png`
(1024x1024 PNG, under 1 MiB).

Run it with:

```sh
python3 main.py
```
