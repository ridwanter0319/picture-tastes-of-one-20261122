The picture is a tight macro of glossy dark chocolate poured in a slow circle around one cocoa-dusted truffle, with a wisp of steam, a dark backdrop, and warm light picking out every shine on the surface — chocolate alone carries the whole frame. To run it, place `entry.png` beside `main.py` and run `python3 main.py`; the program copies that image to `/output/entry.png`.
